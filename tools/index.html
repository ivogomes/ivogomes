Tools

Small utilities I've built for myself, free to use. No tracking: they run in your browser, and your data stays on your device or, for Fin, in a database of your own.

  • TapScore

    Keep score with a tap for tennis, padel, table tennis, pickleball, squash, badminton and volleyball. It handles deuce, tie-breaks and serve, with undo and match stats. Best on a phone or tablet: install it as an app, use it offline, and your matches stay on your device.

    Source on GitHub

  • Teleprompter

    Write and save scripts, read them with scrolling text you can resize and mirror, and keep your phone awake while you present. Scripts stay in your browser, with optional sync across devices.

    Source on GitHub

  • TMX Editor

    Open, view, and edit TMX translation memory files. Search and replace across languages, merge duplicate rows, edit translation-unit metadata, and export — all client-side.

    Source on GitHub

  • Fin

    Take care of your finances: accounts, cards, loans and investments with live prices, scheduled payments, insights, net worth and savings goals. Your data lives in your own free Supabase database, set up once with the steps in its source.

    Source on GitHub
